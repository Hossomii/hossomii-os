# HOSSOMII OS

HOSSOMII OS é um portfólio interativo apresentado como um sistema
operacional fictício.

Em vez de navegar por uma página tradicional com seções como
"Sobre", "Projetos" e "Contato", o visitante recebe acesso a um
computador e pode descobrir essas informações explorando o próprio
sistema.

A experiência é inspirada principalmente pela estética dos computadores
do início dos anos 2000, especialmente Windows XP, combinada com uma
camada narrativa mais moderna e algumas influências de interfaces de
jogos.

---

## A experiência

Ao acessar o projeto, o visitante não encontra imediatamente o portfólio.

Ele primeiro precisa acessar remotamente uma máquina chamada:

HOSSOMII-01

A partir daí, o sistema passa por autenticação, recuperação de sessão
e inicialização até finalmente chegar à Área de Trabalho.

A ideia é que cada parte tradicional de um portfólio tenha uma
representação dentro do computador.

---

## Desktop

O desktop funciona como a principal área de exploração.

Atualmente possui:

- Meu Computador
- Meus Projetos
- Meus Documentos
- Terminal
- Lixeira

As janelas podem ser:

- abertas;
- arrastadas;
- minimizadas;
- maximizadas;
- restauradas;
- fechadas.

A barra de tarefas também acompanha as aplicações abertas.

---

## Meu Computador

O sistema possui uma estrutura de arquivos própria.

O visitante pode navegar pelo Disco Local, entrar em diretórios e
explorar diferentes áreas do computador.

Entre elas estão:

Meus Documentos

e

Meus Projetos

Atualmente os projetos disponíveis são:

### TNT Basketball

Projeto desenvolvido em Unity e C#.

### Médicos & Dentistas

Projeto web desenvolvido para uma experiência relacionada à área da saúde.

Mais informações sobre cada projeto serão apresentadas dentro do próprio
sistema conforme seu desenvolvimento avança.

---

## Meus Documentos

A ideia é transformar informações que normalmente ficariam espalhadas
por um portfólio em arquivos que façam sentido dentro de um computador.

Entre os documentos planejados estão:

- apresentação;
- informações sobre o desenvolvedor;
- currículo;
- outros arquivos relacionados à trajetória profissional.

---

## Terminal

O HOSSOMII OS também terá um Terminal funcional.

Ele não será apenas uma animação.

O Terminal utilizará o mesmo sistema de arquivos visto no Explorer,
permitindo que diferentes partes do computador interajam entre si.

A intenção é permitir comandos simples de navegação e exploração sem
exigir conhecimento prévio de terminal do visitante.

---

## Lixeira

A Lixeira terá comportamento real dentro do sistema.

Arquivos enviados para ela deixarão de aparecer em sua localização
original e poderão alterar o estado visual da própria Lixeira.

Porém, nem tudo dentro do HOSSOMII OS foi feito para ser apagado.

Alguns arquivos são protegidos.

Outros talvez seja melhor simplesmente deixar onde estão.

---

## Segredos do sistema

HOSSOMII OS foi projetado para recompensar curiosidade.

Algumas ações podem produzir comportamentos inesperados.

Existem arquivos que parecem estranhos.

Existem partes do sistema que talvez não estejam ali apenas por estética.

E algumas decisões aparentemente inocentes podem ter consequências
maiores do que o visitante esperava.

O sistema também poderá reconhecer determinadas descobertas através de
conquistas.

Nenhum guia oficial revelará todas elas.

---

## Narrativa

Existe uma pequena narrativa por trás do computador.

A sessão de acesso remoto, mensagens técnicas, arquivos do sistema,
falhas e outros detalhes não são apenas elementos decorativos.

A intenção é fazer o visitante sentir que está explorando uma máquina
que já existia antes de ele chegar.

---

## Inspirações

A identidade do projeto combina referências de diferentes experiências:

- sistemas operacionais do começo dos anos 2000;
- Windows XP;
- interfaces de acesso remoto;
- jogos com sistemas diegéticos;
- Watch Dogs;
- The Operator;
- experiências digitais interativas.

Essas referências servem como direção.

O objetivo não é reproduzir nenhuma delas literalmente, mas construir
uma identidade própria para o HOSSOMII OS.

---

## Filosofia do projeto

O projeto foi criado com algumas regras principais.

### Explorar em vez de apenas rolar

Informações importantes devem poder ser descobertas através da interação.

### Funcionalidade antes de decoração

Sempre que possível, uma interface deve realmente funcionar.

Se existe um Explorer, ele deve navegar.

Se existe uma Lixeira, ela deve armazenar itens.

Se existe um Terminal, ele deve entender comandos.

### Surpresas sem prejudicar usabilidade

Easter eggs fazem parte da experiência, mas o visitante nunca deve ficar
preso permanentemente ou precisar conhecer programação para continuar.

### Nostalgia com identidade própria

A interface pode lembrar computadores antigos sem simplesmente copiar
um sistema operacional existente.
